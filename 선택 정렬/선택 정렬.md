# 선택 정렬
배열의 요소들 반복하며 작은 숫자를 찾아 정렬되지 않은 영역의 맨 앞의 요소와 교환 후 확정하고 1회 차 반복을 종료한다. 이후 확정된 요소를 제외하고 다시 똑같은 과정으로 반복한다.

## 동작 원리
1. 배열 요소 전체 `[2, 5, 3, 6, 5, 1]` 반복하며 가장 작은 숫자를 찾는다.  
2. 가장 작은 숫자는 `1`이랑 정렬되지 않은 맨 앞의 요소랑 교환한다.  
3. `[2, 5, 3, 6, 5, 1]` → `[1, 5, 3, 6, 5, 2]` 교환한다.  
4. 그럼 이제 교환한 숫자를 제외하고 정렬되지 않은 요소를 반복하며 똑같은 과정으로 찾아 정렬한다.
5. 찾는 과정
    1. `[1, 5, 3, 6, 5, 2]` → `1` 제외하고 나머지 반복  
    2. `[1, 2, 3, 6, 5, 5]` → `1, 2` 제외하고 나머지 반복
    3. `[1, 2, 3, 6, 5, 5]` → 이미 정렬되어 있어도 반복하여 확인 `1, 2, 3` 제외하고 반복
    4. `[1, 2, 3, 5, 5, 6]` → `1, 2, 3, 5` 제외하고 나머지 반복
    5. `[1, 2, 3, 5, 5, 6]` → 이미 정렬되어 있어도 반복하여 확인 `1, 2, 3, 5, 5` 제외하고 반복
    6. `[1, 2, 3, 5, 5, 6]` → 종료
