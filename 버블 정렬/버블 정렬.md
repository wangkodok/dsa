# 버블 정렬
배열의 첫 번째 요소랑 두 번째 요소를 비교하여 첫 번째 요소가 크면 자리를 바꾸면서 배열 끝까지 반복하고 다시 반복하여 요소가 자리를 한 번도 바꾸지 않았다면 종료한다.

## 동작 원리
배열에서 `0번, 1번` `1번, 2번` ... `7번, 8번` `8번, 9번` 순서대로 비교하고 작은 값은 앞으로 큰 값은 뒤로 보낸다.
1. `[2, 3, 3, 1, 6, 8]` 배열에서 2 < 3 비교
2. `[2, 3, 3, 1, 6, 8]` 배열에서 3 < 3 비교
3. `[2, 3, 3, 1, 6, 8]` 배열에서 3 < 1 비교하고 교환
4. `[2, 3, 1, 3, 6, 8]` 배열에서 3 < 6 비교
5. `[2, 3, 1, 3, 6, 8]` 배열에서 6 < 8 비교
6. 배열의 마지막 요소까지 1회 반복하여 비교한 결과 아직 정렬이 안 됐다. 따라서 다시 2회 반복한다.
7. `[2, 3, 1, 3, 6, 8]` 배열에서 2 < 3 비교
8. `[2, 3, 1, 3, 6, 8]` 배열에서 3 < 1 비교하고 교환
9. `[2, 1, 3, 3, 6, 8]` 배열에서 3 < 3 비교
10. `[2, 1, 3, 3, 6, 8]` 배열에서 3 < 6 비교
11. `[2, 1, 3, 3, 6, 8]` 배열에서 6 < 8 비교
12. 배열의 마지막 요소까지 2회 반복하여 비교한 결과 아직 정렬이 안 됐다. 따라서 다시 3회 반복한다.
13. `[2, 1, 3, 3, 6, 8]` 배열에서 2 < 1 비교하고 교환
14. `[1, 2, 3, 3, 6, 8]` 위와 같은 동작 원리대로 동작한다.
