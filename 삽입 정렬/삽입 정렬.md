# 삽입 정렬
정렬되지 않은 배열의 0번 요소를 정렬된 영역으로 간주하고 1번 요소와 비교하면서 배열의 요소가 가장 작은 위치가 될 때 까지 왼쪽으로 이동하면서 같은 과정으로 반복한다.

## 동작 원리
`[5, 2, 1, 3]` 배열에서 숫자 **5가 정렬된 영역으로 간주 5 ＞ 2 비교하여 작은 숫자가 될 때까지 왼쪽으로 이동**하면 `[2, 5, 1, 3]` 된다. 이와 같은 과정으로 반복하면 `[2, 5, 1, 3]` → `[2, 1, 5, 3]` → `[1, 2, 5, 3]` 배열의 요소가 가장 작은 위치가 될 때까지 왼쪽으로 이동하고 `[1, 2, 5, 3]` → `[1, 2, 3, 5]` 결과가 나온다.
